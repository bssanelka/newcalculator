# Калькулятор и учёт товаров

Проект для демонстрации навыков HTML, CSS и JavaScript.

## Возможности
- Калькулятор с функциями sin, cos, tg, exp, log
- Учёт товаров с добавлением в таблицу
- Два способа добавления: прямой и через массив объектов

## Технологии
- HTML5
- CSS3
- JavaScript (без библиотек)
